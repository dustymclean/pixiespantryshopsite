System blocks.

Order processing

We batch process orders daily. If the hardware is in stock, it moves to the fulfillment line within 24 hours.

Tracking

Tracking numbers are generated at the manifest stage. You will receive an automated ping when the carrier scans the box.

Discreet packaging

Plain boxes. Standard return address. The contents of your system are nobody's business but yours.

Manual orders

Custom bundles or special-order hardware require manual invoicing. Fulfillment timelines will be set during the quote.

Support routing

If a package stalls in transit, use the Discord support channel with your order number. We will run the trace.

Final operating principle.

Pixie's Pantry does not sell clutter. Every component on this site has been audited for material safety, cleanability, and system compatibility. If it's in the registry, it works.
